### MODULE 6 — Essential n8n Nodes & Core Building Blocks
- 10 essential nodes at a glance
- Logic Nodes
- IF Node — binary Yes/No decision gate
- Switch Node — multi-path routing based on rules
- Merge Node — combines two or more data streams
- Data Nodes
- Set Node — add, remove or rename data fields
- Split in Batches Node — divide a large list into smaller groups
- Aggregate Node — collect multiple items into a single output
- Control Nodes
- HTTP Request Node — connect to external API/web service
- Code Node — custom JavaScript or Python logic
- Wait Node — pause workflow for a set duration
- Error Trigger Node — catch and handle errors
- Choosing the right node for the task
- Practice exercises: node identification and configuration
