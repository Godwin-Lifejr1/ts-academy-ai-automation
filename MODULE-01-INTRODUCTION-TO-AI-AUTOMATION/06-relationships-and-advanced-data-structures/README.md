# Module 1 — Topic 6: Relationships & Advanced Data Structures

## Core data structures

### String
Text data.
Examples: "John", "Port Harcourt", "Customer complaint"

### Number
Numerical data.
Examples: 25, 1000, 20000000, 3.14

### Boolean
A value with two possible states:
true / false

Example:
payment_confirmed = true

### Object
A collection of related key-value pairs.

Example:
{
  "name": "John",
  "location": "Abuja",
  "budget": 20000000
}

### Array
A collection/list of multiple items.

Example:
[
  "John",
  "Mary",
  "David"
]

## Object + array relationship
In a structure where "customers" contains a list of customer records:
- The entire structure is an object.
- customers is an array.
- Each customer record is an object.

Mental model:
Object → Array → Objects → Fields → Values

## JSON
JSON means JavaScript Object Notation. It is a common structured format for exchanging data between applications.

Example automation:
Form → JSON → Automation platform → CRM

## Data relationships
- One-to-one: one record relates to one other record.
- One-to-many: one record relates to multiple records.
- Many-to-many: multiple records can relate to multiple other records.

Example one-to-many:
One customer → many items in an order.
