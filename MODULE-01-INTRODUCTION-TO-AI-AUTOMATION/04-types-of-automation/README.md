# Module 1 — Topic 4: Types of Automation

## Learning objectives
Understand rule-based automation, workflow automation, API-based automation, AI-powered automation, attended automation, and unattended automation.

## 1. Rule-Based Automation
A system follows predefined IF/THEN rules.

Example:
IF a customer's budget is at least ₦20,000,000, THEN notify a senior sales representative.

## 2. Workflow Automation
A workflow connects multiple automated steps into one process.

Example:
Form submission → save customer data → notify sales team → create CRM lead → send confirmation.

A workflow may contain rules, APIs, AI, and human approval. Workflow describes the connected process, not one individual technology.

## 3. API-Based Automation
An API (Application Programming Interface) provides a structured way for software systems to communicate.

Example:
Website → automation platform → CRM API → new CRM lead.

APIs are important because modern automation often connects multiple applications.

## 4. AI-Powered Automation
AI is used when information requires interpretation, classification, extraction, generation, or other AI capabilities.

Example:
Customer message → AI extracts requirements → automation stores the data → CRM is updated → sales representative is notified.

## 5. Attended vs Unattended Automation

### Attended
A human initiates or participates in the process.

Example:
A sales employee clicks "Generate Proposal" and automation creates the proposal.

### Unattended
The workflow runs without a person actively starting each execution.

Example:
A scheduled process collects yesterday's sales and emails a report to management.

## Key distinction
- Rule-based = predefined decision logic.
- Workflow = connected sequence of steps.
- API-based = systems communicate.
- AI-powered = AI interprets/generates information and automation acts on the result.
- Attended = human involvement during execution.
- Unattended = workflow runs automatically.

These categories can overlap. A single system can be an unattended workflow that uses AI, APIs, and rules.

## Practical exercise
Scenario: A property customer sends a natural-language enquiry. AI extracts the customer's requirements, the workflow stores the information, an API sends the lead to a CRM, and a notification is sent to a sales representative.

Questions:
1. Which part is AI-powered?
2. Which part is workflow automation?
3. Where could an API be used?
4. Give one rule that could be added.
5. Is the process attended or unattended?
6. Why might AI be useful for a natural-language enquiry?

## Checkpoint
Key lesson: choose the simplest technology that solves the problem. Do not add AI when ordinary rules are sufficient. Use AI when the input requires interpretation or generation.
