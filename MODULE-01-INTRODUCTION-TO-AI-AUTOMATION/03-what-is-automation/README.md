# Module 1 — Topic 3: What is Automation?

## Definition
Automation is the use of technology to perform tasks or processes automatically with little or no human intervention.

## Core model
Trigger → Action → Result

Example:
- Trigger: customer submits a property enquiry form
- Actions: save information to Google Sheets, notify sales, send confirmation
- Result: customer record is created and relevant people are notified

## Automation vs AI
Traditional automation follows predefined instructions.

AI can interpret patterns, meaning, natural-language input, or generate content.

A useful mental model:
- Automation executes.
- AI interprets or generates when the task requires it.

## Types introduced
- Rule-based automation
- Workflow automation
- API-based automation
- AI-powered automation

## Checkpoint
Passed — user correctly identified the trigger, actions, results, and explained why AI was unnecessary for a predefined form-to-sheet/email workflow.
